# Research Task 7: Ethics of Synthetic Representation

## Project Overview

This repository contains my work for Research Task 7, which examines the ethics and governance of synthetic media. The project builds directly on my hands-on synthetic audio experiment from Task 6 and moves from creating and evaluating synthetic media to reasoning about how its use should be governed.

The project has two main phases. Phase A analyzes the ethical challenges of synthetic representation through the dimensions of truth, consent, context, and scale. Phase B translates those ethical observations into an operational synthetic-media policy for a specific organizational setting.

Rather than treating disclosure, provenance, or detection as complete solutions, this project considers their practical value as well as their limitations.

## Organizational Context

For Phase B, I chose a **University Communications Office** as the organizational setting.

University communications may include websites, social media, informational videos, audio messages, accessibility content, translations, event promotions, and official announcements. Synthetic media can provide legitimate benefits in this environment, but university communications also carry institutional authority.

This makes the setting useful for examining when synthetic media should be permitted, when additional consent or review should be required, and when its use should be refused.

## Repository Structure

### [Phase A: Ethical Analysis](Phase_A_Ethical_Analysis.md)

Analyzes synthetic representation across four ethical dimensions:

- Truth
- Consent
- Context
- Scale

It also evaluates the strengths and limitations of disclosure, provenance and content credentials, detection systems, legal and regulatory approaches, platform policies, and professional or organizational norms.

### [Phase B: Synthetic Media Responsible Use Policy](Phase_B_Synthetic_Media_Policy.md)

Provides an operational policy for synthetic-media use by a University Communications Office. The policy addresses:

- Permitted uses
- Prohibited uses
- Consent requirements
- Disclosure requirements
- Provenance and content credentials
- Review and approval
- Publication and distribution
- Incident response
- Refusal criteria

### [Policy Limitations and Stress Test](Policy_Limitations.md)

Stress-tests the Phase B policy by examining:

- Ambiguous boundaries and human judgment
- Limitations of consent
- Disclosure and context loss
- Provenance and detection limitations
- Third-party and bad-faith misuse
- Scale and automation risks
- Dependence on good-faith compliance
- Residual risk

## Connection to Task 6

This project builds directly on my previous synthetic-media experiment:

**[Task 6: Constructing and Evaluating Synthetic Media](https://github.com/rbhosle169/Task_06_Deep_Fake)**

In Task 6, I created two synthetic audio versions of the same analytical script using ElevenLabs. The versions used different synthetic voices, allowing me to compare how voice and delivery affected the perceived tone and authority of otherwise identical information.

I also tested both artifacts using Hive Moderation's AI-generated audio detection system. The detector identified the two artifacts as likely AI-generated with scores of approximately 99.3% and 99.2%.

That experience informed the ethical reasoning in this project. In particular, it demonstrated that synthetic representation can change how identical information is perceived and that detection can provide useful evidence without resolving broader questions about truth, consent, context, or appropriate use.

## Key Takeaways

The central lesson from this project is that responsible synthetic-media governance cannot depend on a single safeguard.

Consent does not replace disclosure. Disclosure can become separated from content. Provenance can be removed or lost. Detection provides evidence rather than certainty. Human review is also imperfect and becomes increasingly difficult as synthetic-media production scales.

For these reasons, the policy developed in this project combines multiple safeguards: consent, disclosure, provenance, factual review, approval requirements, incident response, and explicit refusal criteria.

The goal is not to eliminate every possible risk. It is to create a practical framework for deciding when synthetic media can be used responsibly, when additional oversight is necessary, and when it should not be used at all.
